# Nitiphum Kongphet — GitHub Pages Portfolio

## Deploy
1. Upload the contents of this folder to a GitHub repository.
2. Keep `index.html` at the repository root.
3. Optional: place the approved professional photo at `assets/profile.jpg`.
4. Enable GitHub Pages from the repository's Pages settings.

## Privacy
- No Google Drive link is included in the website.
- No company/client names are displayed.
- Case details describe scope of work only.
- The contact form opens the user's email client; it does not upload submissions to Drive.

## Important source limitation
The current package is based on the supplied HTML/CV-derived content available in this conversation and the public portfolio reference. The provided Google Drive folder could not be enumerated into its individual files from the available web access, so no unverified Drive content has been invented or copied into the site.
